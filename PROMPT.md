Build a tiny browser game in a single self-contained HTML file called Starfall: a canvas arcade game where the player slides a glowing basket left and right with the arrow keys (or by dragging with mouse or touch) to catch falling stars worth 10 points each while dodging falling rocks — each rock costs one of 3 lives. Show score, lives and best score (saved in localStorage), a start screen with instructions, a game-over screen with a restart button, a colorful night-sky gradient with twinkling background stars, and smooth animation with requestAnimationFrame. No external assets, no libraries, no sound — everything inline.
