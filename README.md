# Starfall — a tiny game built from one prompt

A tiny browser arcade game in a single self-contained `index.html` — no
libraries, no external assets, no sound. Built by an AI coding agent from
exactly ONE prompt (see `PROMPT.md`).

**How to play:** slide the glowing basket left and right with the arrow keys
(or drag with mouse / touch). Catch falling stars for +10 points each. A
falling rock costs one of your 3 lives. Best score is saved in localStorage.

**Run it:** open `index.html` in any browser. Add `?demo=1` to the URL and
the basket plays itself.
